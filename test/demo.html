AEM Edge Delivery Services — Developer Overview

[00:00] In this video, we cover how AEM Edge Delivery Services works from a developer's perspective.

[00:15] Edge Delivery Services uses a file-based authoring model where content lives in SharePoint or Google Drive.

[00:30] The platform delivers pages from the edge with near-zero TTFB, scoring 100 on Core Web Vitals out of the box.

[00:50] Developers build blocks using plain HTML, CSS, and JavaScript — no framework required.

[01:10] Each block exports a single decorate() function that receives the block DOM and transforms it into the final UI.

[01:30] The Universal Editor enables WYSIWYG authoring on top of the same block model, bridging document-based and traditional CMS workflows.

[01:55] By the end of this video you will understand the project structure, the block pipeline, and how to deploy your first EDS site.
