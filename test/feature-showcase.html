Block Architecture
Every UI Component is a Block

In AEM Edge Delivery Services, the entire page is composed of blocks — self-contained units of HTML, CSS, and JavaScript that each export a single decorate() function.

  • Zero framework dependencies
  • Loaded only when the block is on the page
  • Authored visually in Universal Editor

Component Model
Schema-Driven Field Definitions

Block fields are defined in _blockname.json using the xwalk plugin schema. The Universal Editor reads this schema to render the properties panel — no custom UI code required.

  • reference — image asset picker
  • richtext — inline rich-text editor
  • multiselect named style — appends CSS class variants

Resolving Links Across Authoring Modes

AEM auto-links plain text URLs in text fields on the live page. The block reads anchor.getAttribute('href') to recover the original authored value — preserving relative paths and hash anchors.
